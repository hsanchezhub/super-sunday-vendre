# Vendre · Super Sunday Lyon

Présentation de Sancho et Greg, Super Sunday Lyon, dimanche 25 octobre 2026.

**Lien de projection : https://hsanchezhub.github.io/super-sunday-vendre/**

1. Ouvrir le lien dans Chrome sur l'ordinateur relié au vidéoprojecteur.
2. Appuyer sur **F** pour le plein écran.
3. Appuyer sur **P** pour ouvrir la fenêtre de notes de l'orateur (à garder sur l'écran de l'ordinateur, pas sur le projecteur).
4. Avancer avec la flèche droite, la barre d'espace ou la télécommande.

Sans connexion internet : télécharger ce dépôt (bouton **Code**, puis **Download ZIP**), le décompresser et double-cliquer sur `index.html`.

Détails et raccourcis : [Mode d'emploi](Mode%20d'emploi.md).
